📅 Karelin's Log: личный блог на FastAPI + PostgreSQL


Цель проекта — построить приложение, которое я могу масштабировать до полноценного продукта с пользователями, комментариями и миграциями базы данных.

Личный блог с чистой слоистой архитектурой, спроектированный для постепенного наращивания функционала: пользователи, комментарии, миграции. Проект развивается как реальный продукт и хобби.


📋 Основные функции
- Полный CRUD для постов: создание, чтение (одного и списка), обновление (PATCH) и удаление.
- Валидация входных данных через Pydantic-схемы.
- Защита от лишних полей в PATCH-запросах (extra="forbid").
- Управление схемой БД через миграции Alembic.
- Покрытие CRUD интеграционными тестами (репозиторий, сервис, контроллер).

✨ Технологии (Стек)
- Серверная часть / ORM: Python, FastAPI, SQLModel
- База данных: PostgreSQL (асинхронный доступ через sqlalchemy[asyncio] и asyncpg)
- Миграции: Alembic
- Тестирование: pytest, pytest-asyncio
- Управление окружением: venv


🏗️ Архитектура проекта
```text
app/
├── controllers/            # HTTP-слой: эндпоинты FastAPI, обработка запросов и ответов
|   └── ...                 # (HTML-шаблоны — в разработке)
├── core/                   # Конфигурация приложения (настройки, переменные окружения)

|   └── repositories/       # Репозитории: CRUD-операции с БД
|   └── session.py          # Движок, фабрика сессий, зависимость get_session
├── models/                 # ORM-модели SQLModel (описание таблиц)
├── schemas/                # Pydantic-схемы (валидация запросов и ответов API)
├── services/               # Бизнес-логика: правила и проверки (title и т.д.)
└── main.py                 # Точка входа: сборка FastAPI-приложения
tests/
├── integration/            # Интеграционные тесты (HTTP, БД, репозитории, сервисы)
└── unit/                   # Юнит-тесты (в разработке)
```

🔐 Переменные окружения

.env:
- DATABASE_URL — строка подключения к рабочей БД (postgresql+asyncpg://postgres:password@localhost:5432/database)
- DEBUG_SQLALCHEMY — включить SQL-логи (true/false)
- APP_PORT — порт приложения (по умолчанию 8000)

.env.test:
- TEST_DATABASE_URL — строка подключения к тестовой БД (должна содержать _test)


🗄️ Миграции базы данных

Проект использует Alembic для управления схемой БД.

Перед первым запуском примените миграции:
- alembic upgrade head

Если вы изменили модели (например, добавили поле в Post), создайте новую миграцию:
- alembic revision --autogenerate -m "Описание изменений"
- alembic upgrade head


🚀 Запуск проекта


Для работы требуется Python 3.14 и установленная база данных PostgreSQL.


Локальный запуск
- Клонируйте репозиторий: git clone https://github.com/KarelinIvan/Karelin-s-Log
- Создайте виртуальное окружение: python -m venv venv
- Активация виртуального окружения:
    - Для Windows (CMD/PowerShell): venv\Scripts\activate
    - Для Linux/macOS: source venv/bin/activate
- Установите зависимости: pip install -r requirements.txt
- Скопируйте файл .env.example в корневую директорию как .env. Укажите корректные параметры подключения к вашей базе данных
- Примените миграции: alembic upgrade head
- Запустите сервер разработки: uvicorn app.main:app --reload


🧪 Тестирование

Проект покрыт интеграционными тестами:
- Проверка подключения к PostgreSQL и создания таблиц.
- Тестирование слоя репозитория (CRUD-операции с БД).
- Тестирование бизнес-логики сервиса (проверки title, обработка ошибок).
- Тестирование HTTP-эндпоинтов через AsyncClient (статусы 200, 201, 204, 400, 404, 409).

▶️ Запуск тестов
- Создайте тестовую базу данных: CREATE DATABASE database_test;
- Скопируйте .env.example в .env.test и укажите TEST_DATABASE_URL.
- Запустите тесты:
    - Запуск всех тестов: pytest -v
    - Запуск интеграционных тестов: pytest tests/integration/ -v
    - Запуск юнит тестов: pytest tests/unit/ -v
