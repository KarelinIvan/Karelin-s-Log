📅 Karelin's Log: личный блог на FastAPI + PostgreSQL


Цель проекта — построить приложение, которое я могу масштабировать до полноценного продукта с пользователями, комментариями и миграциями базы данных.

Я использовал его для глубокого погружения в современные подходы к промышленной разработке на Python: Clean Architecture (слоистая архитектура), SQLModel/SQLAlchemy для работы с PostgreSQL, а также автоматизацию тестирования с помощью Pytest-asyncio.




📋 Основные функции


✨ Технологии (Стек)
- Серверная часть / ORM: Python 3.14+, FastAPI 0.143.3, SQLModel 0.48.0
- База данных: PostgreSQL (асинхронный доступ через sqlalchemy[asyncio] 2.1.5 и asyncpg 0.32.0)
- Тестирование:
- Управление окружением: venv


🏗️ Архитектура проекта
```text
app/
├── api/            # Роутеры: принимают HTTP-запросы и вызывают сервисы.
├── core/           # Конфигурация приложения и общие утилиты.
├── database/       # Подключение к БД, сессии и репозитории (чистый CRUD).
├── models/         # ORM-модели SQLModel: таблицы базы данных.
├── schemas/        # Pydantic-схемы: валидация запросов и ответов API.
├── services/       # Бизнес-логика: правила блога (что разрешено делать).
└── main.py         # Точка входа: сборка FastAPI-приложения.
tests/
├── integration/    # Тесты эндпоинтов (через HTTP-клиент)
└── unit/           # Тесты сервисов и репозиториев (изоляция)
```

🚀 Запуск проекта


Для работы требуется Python >= 3.14 и установленная база данных PostgreSQL.


Локальный запуск
- Клонируйте репозиторий: git clone https://github.com/KarelinIvan/Karelin-s-Log
- Создайте виртуальное окружение: python -m venv venv
- Автивация виртуального окружения:
    - Для Windows (CMD/PowerShell): venv\Scripts\activate
    - Для Linux/macOS: source venv/bin/activate
- Установите зависимости: pip install -r requirements.txt
- Скопируйте файл .env.example в корневую директорию как .env. Укажите корректные параметры подключения к вашей базе данных
- Запустите сервер разработки: uvicorn app.main:app --reload


📚 Документация
После запуска документация будет доступна по адресу:
- Swagger UI: http://127.0.0.1:8000/docs
- ReDoc: http://127.0.0.1:8000/redoc

🧩 Тестирование

Проект покрыт тестами:
- Интеграционные тесты: проверка подключения к PostgreSQL, работа с БД на уровне репозитория.
- Юнит-тесты сервисов: изолированное тестирование бизнес‑логики без запуска базы данных.
